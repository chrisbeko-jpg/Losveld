# LOS!

**Boek. Poort dicht. Hond los.**

Eerste MVP van losveld.nl: een Nederlandse marktplaats voor het per tijdslot boeken en verhuren van privéterreinen voor honden.

## MVP
- Mobile-first publieke homepage
- Zoek- en veldpresentatie
- Exclusieve reserveringspropositie
- Hostpropositie en verdienvoorbeeld
- Basis voorbereid voor boekingen, accounts, reviews en betalingen

## Stack
Next.js / React. Gepland: Supabase voor database/auth/storage en Stripe Connect voor marketplacebetalingen en host-uitbetalingen.

## Lokaal starten
```bash
npm install
npm run dev
```
